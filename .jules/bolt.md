## 2024-07-02 - Next.js Image with Framer Motion and Error Fallbacks
**Learning:** When migrating from native `<img>` tags to Next.js `<Image>` while preserving Framer Motion animations, applying `motion` directly to the Next.js `Image` wrapper (e.g., `<motion.img>`) causes issues. Instead, the `<Image />` component should be wrapped in a `<motion.div>`. Additionally, when using an `onError` fallback handler with Next.js images, you must explicitly clear `e.target.srcset` (e.g., `e.target.srcset = ""`) because browsers prioritize the automatically generated `srcset` over `src`, causing the fallback image to fail to display.
**Action:** Always wrap Next.js `<Image>` components in `<motion.div>` when combining with Framer Motion. Ensure `e.target.srcset = ""` is present in `onError` fallback handlers when migrating to `next/image`.
