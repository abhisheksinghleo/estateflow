## 2024-07-04 - [Optimizing images with Framer Motion and next/image fallback]
**Learning:** When migrating from native `<img>` to `next/image` to optimize rendering and LCP, you cannot apply Framer Motion directly to the image wrapper `<motion.img>` if using the `fill` property without potential issues. Instead, wrap `next/image` in a `<motion.div>` with a relative layout. Additionally, when handling `onError` fallbacks with `next/image`, you must explicitly clear `e.target.srcset` (`e.target.srcset = ""`) because browsers prioritize the auto-generated `srcset` over `src`, preventing the fallback image from displaying if the original source fails.
**Action:** Always wrap `next/image` in a `<motion.div>` with `position: relative` and explicit dimensions when preserving Framer Motion animations. Ensure `e.target.srcset = ""` is explicitly set in `onError` handlers when migrating fallback behaviors to `next/image`.
