## 2026-05-07 - [In-Memory SWR Caching]
**Learning:** Adding an in-memory SWR (Stale-While-Revalidate) cache directly to a centralized data-fetching hook (like `useApi.js`) provides massive perceived performance improvements for repeated visits to the same page/data without the overhead of heavy external libraries like React Query. However, when implementing this, one must carefully derive state from props during render (`if (cacheKey !== currentCacheKey)`) to avoid infinite re-renders or tearing when navigating dynamic routes (like `/properties/[slug]`) that don't remount the component.
**Action:** When creating custom data-fetching hooks with caching, always consider dynamic route navigation and derive state during render to seamlessly update cache keys and fetch states without unmounting components.
