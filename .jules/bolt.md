## 2026-06-28 - Migrating Next.js Image with Framer Motion and onError Fallbacks
**Learning:** When migrating from a native `<img>` tag (or `<motion.img>`) to the Next.js `<Image>` component, applying Framer Motion directly to the Next.js image wrapper can cause issues. Also, when using an `onError` fallback handler to load a default image, browsers prioritize the automatically generated `srcset` over `src`, causing the fallback image to fail to display.
**Action:** When preserving Framer Motion animations during a migration to Next.js `<Image>`, wrap the `<Image />` component in a `<motion.div>` instead of trying to apply motion directly to the Next.js image wrapper (e.g., avoid `<motion.img>`). When migrating an `onError` fallback handler, you must explicitly clear `e.target.srcset` (e.g., `e.target.srcset = ""`) in the handler.
