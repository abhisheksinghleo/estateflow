## 2026-06-23 - Next.js Image with Framer Motion and Fallback Handling
**Learning:** When migrating from native `<img>` tags to Next.js `<Image />` and attempting to preserve Framer Motion animations, applying `motion` directly to the `Image` wrapper (e.g. `<motion.img>`) causes issues. Additionally, when migrating an `onError` fallback handler, simply changing `e.target.src` is insufficient because `next/image` automatically generates a `srcset`. The browser prioritizes the `srcset` over `src`, causing the fallback image to fail to display if `srcset` is not cleared.
**Action:** When migrating to Next.js `<Image>`, wrap the component in a `<motion.div>` for animations instead of animating the image tag directly. In the `onError` handler, explicitly clear the `srcset` (i.e., `e.target.srcset = ""`) along with updating `e.target.src` to ensure fallback images render correctly.
