## 2026-07-03 - Next.js Image with Framer Motion and Fallback Optimization
**Learning:** When migrating native `<img>` tags to Next.js `<Image>` within Framer Motion components, wrapping `<Image>` in `<motion.div>` preserves animations correctly instead of trying to apply motion directly to the Next.js component. Additionally, when porting an `onError` fallback handler to Next.js `<Image>`, you must explicitly clear `e.target.srcset` (e.g., `e.target.srcset = ""`). If not, browsers prioritize the automatically generated `srcset` over the fallback `src`, causing the fallback image to fail to display.
**Action:** When migrating to Next.js `<Image>`, always wrap it in `<motion.div>` for animations, include `fill` on the image and relative/absolute/fixed positioning with explicit dimensions on the parent, and explicitly clear `e.target.srcset` in the `onError` fallback handler. Use `sizes` attribute for optimized responsive loading.
