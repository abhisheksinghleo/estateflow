## 2026-07-15 - Z-Index requirement when replacing native img with Next.js Image fill\n**Learning:** When replacing a native `<img>` tag with Next.js `<Image fill />`, the image relies on absolute positioning. This can cause sibling elements that are also absolutely positioned (like overlay gradients, badges, or buttons) to become hidden behind the image if they don't have an explicit z-index.\n**Action:** Whenever migrating to `<Image fill />`, proactively check and apply appropriate z-index classes (e.g., `z-10`, `z-20`) to sibling overlay elements to preserve the visual stacking order.
