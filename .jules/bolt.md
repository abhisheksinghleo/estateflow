## 2024-07-06 - Migrating native `<img>` to Next.js `<Image>` with Framer Motion and `onError` fallback
**Learning:** When preserving Framer Motion animations during a migration from native `<img>` to Next.js `<Image>`, the `<Image />` component should be wrapped in a `<motion.div>` instead of trying to apply motion directly to the Next.js image wrapper (e.g., avoid `<motion.img>`). Additionally, when migrating an `onError` fallback handler, you must explicitly clear `e.target.srcset` (e.g., `e.target.srcset = ""`) in the handler. Browsers prioritize the automatically generated `srcset` over `src`, which can cause the fallback image to fail to display.
**Action:** Always wrap `next/image` in a `<motion.div>` for animations and ensure `e.target.srcset = ""` is present in `onError` handlers to correctly render fallbacks.
