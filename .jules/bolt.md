## 2024-05-06 - Implement SWR Caching for `useApi` hook
**Learning:** Adding a `cacheKey` parameter to the `useApi` hook for an in-memory Map cache acts as a Stale-While-Revalidate pattern. On dynamic routes (e.g. Next.js app router navigating from `/buy` to `/buy?location=NY`), the component does not unmount but simply re-renders. If the initial cached state is only evaluated on mount, the cache might mismatch the updated `cacheKey` and display outdated data or unnecessary loading states.
**Action:** When implementing SWR caching with React hooks in dynamic route environments, always use a derived state pattern (`if (cacheKey !== currentCacheKey) { setCurrentCacheKey(cacheKey); ... }`) to immediately flush and synchronize internal state with the new prop/cacheKey before the initial render cycle completes, avoiding flash of loading state or stale data without unmounting components.
