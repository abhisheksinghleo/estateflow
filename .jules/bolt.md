## 2024-04-26 - Memoize expensive array operations specific to listing views
**Learning:** In Next.js client components handling large arrays of data (e.g., `allBuyProperties` or `rentProperties`), operations like filtering and sorting on every render cause significant UI bottlenecks. Without memoization, interacting with input fields (like the URL-based search params or search bars) triggers re-calculations, blocking the main thread.
**Action:** Use `useMemo` to wrap expensive filtering and sorting logic (e.g. `applyFilters` and subsequent `sort`) on lists of properties. Ensure dependencies include only what changes the list (the raw data array, the current active filters, and the sort value) so that re-renders from state changes elsewhere in the component do not unnecessarily recalculate the list.
